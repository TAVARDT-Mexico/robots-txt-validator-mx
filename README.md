Inspeccion de directivas robots.txt para asegurar el acceso adecuado de rastreadores y evitar desindexaciones no planificadas en Mexico.

Desarrollado y mantenido por el equipo de ingenieria web y rastreabilidad de **TAVARDT Mexico**.

***

## Capacidades de Auditoria de Robots.txt

* **Deteccion de Bloqueos de Indexacion**: Localizacion de instrucciones disallow que afecten el trafico organico en Mexico.
* **Gobernanza de Agentes de IA y Buscadores**: Gestion granular de acceso para Googlebot, Bingbot y rastreadores de inteligencia artificial.
* **Declaracion de Sitemaps**: Enlace perimetral con archivos XML de mapa de sitio y verificacion de accesibilidad.
* **Analise de Reglas de Exclusion**: Supervision de rutas sensibles y directivas restrictivas.
* **Metrica de Calidad de Rastreo**: Calificacion tecnica de 0 a 100 con directrices de saneamiento perimetral.

***

## Instalacion y Ejecucion

Requiere Python 3.8 o superior con la biblioteca estandar.

```bash
git clone https://github.com/TAVARDT-Mexico/robots-txt-validator-mx.git
cd robots-txt-validator-mx
python robots_validator.py https://ejemplo.mx
```

Para formato estructurado JSON:

```bash
python robots_validator.py https://ejemplo.mx -json
```
